WORLD INPUT:
Keyboard and mouse:
- W, A, S, D - move camera around; unlocks camera if it is locked
- Z - show/hide all UI
- Tab - show/hide info panel about selected space object
- LMB - go into selected system or planet, or open district view; press buttons
- RMB - lock camera on the selected object/unlock camera if no object is selected
- Mouse Wheel - zoom in or out
- Move mouse around to select space objects or buttons; selected object is indicated by white rhombus
- Space - pause/resume simulation
- F3 - open/close debug text
- Q - exit planet or system overview or district view
- ESC - open escape menu

Logitech joystick:
- Left Joystick - move camera around; unlocks camera if it is locked
- LB - show/hide all UI
- Y - show/hide info panel about selected space object
- A - go into selected system or planet or open district view; or press selected button
- X - lock camera on the selected object/unlock camera if no object is selected
- LT/RT - zoom in or out
- Right Joystick - Move mouse around to select space objects; selected object is indicated by white rhombus
- RB - pause/resume simulation
- B - exit planet or system overview
- Back - exit game


MENU INPUT:
Keyboard and mouse:
- LMB - Press selected buttons
- ESC - exit opened panels

Logitech joystick:
- Left joystick or D-pad - select another button (depends on the direction)
- A - press selected button
- X - cancel menu input if in the world overview
- B - cancel menu input if in the world overview; close screen if in main menu
- RB - pause/resume simulation if in world overview


INPUT BOX INPUT:
Keyboard and mouse:
- Arrows Left and Right - move left and right the cursor in the input box
- Backspace - remove character at left of the cursor
- Delete - remove character at right of the cursor
- Enter, ESC, LMB - exit input box

Logitech joystick:
- LB and RB - move left and right the cursor in the input box
- B - remove character at left of the cursor
- X - remove character at right of the cursor
- A - exit input box
